# Worm Castings — Wildwood Hills Ranch of Iowa

Public site for Urban Pasture / Wildwood worm castings education, lawn calculator, and kids worm farm.

**Live:** https://yoans.github.io/worm-castings/

## Run locally

```bash
npm install
npm run dev
```

## Routes

| Path | Purpose |
|------|---------|
| `/` | Home |
| `/lawn` | Lawn calculator & ordering info |
| `/learn` | Education pamphlet |
| `/play` | Kids worm farm game |

## Deploy

```bash
npm run deploy
```

Publishes the Vite build to the `gh-pages` branch (GitHub Pages).
